# AGENTS.md

`animovement` is part of the [animovement](https://animovement.dev)
suite — the meta-package that installs, attaches and keeps the suite in
sync.

## Where to look things up

- **This package’s API** —
  <https://animovement.dev/animovement/llms.txt> lists every exported
  function, grouped, with a one-line description. Full help for one
  function, including its exact signature, is at
  `https://animovement.dev/animovement/reference/<function>.md`.
- **Which package owns what** —
  <https://github.com/animovement/animovement-agents> maps the suite:
  the anicore data model, and the verb prefixes each package owns.
- **How we work** —
  [CONTRIBUTING.md](https://github.com/animovement/.github/blob/main/CONTRIBUTING.md).
- **Working with AI tools** —
  [AI.md](https://github.com/animovement/.github/blob/main/AI.md).

These are generated from the source, so unlike a model’s recollection
they cannot drift from the installed package.

## Before you write code here

- **Verify that a function exists, and check its signature**, using the
  reference above. This suite is eight packages that went through a
  split and keeps evolving, so a plausible-sounding name may belong to a
  different package, may have changed signature, or may never have
  existed.
- **Format with [air](https://posit-dev.github.io/air/)**, not styler.
  Every pull request is checked, and formatting failures block merging.
- **Run the tests** — `devtools::test()`. Do not rely on code looking
  correct.
- **Do not push to `main`.** It is protected; open a pull request.
  Checks must pass before merging.
- **Write the pull request title as a [Conventional
  Commit](https://www.conventionalcommits.org/en/v1.0.0/)** —
  `fix(animovement): keep metadata through filter_kalman()`. Merges
  squash, so the title becomes the commit on `main`, and a workflow
  checks it. Types and the breaking-change rule are in
  [CONTRIBUTING.md](https://github.com/animovement/.github/blob/main/CONTRIBUTING.md#commit-messages).
- **Fill in the pull request template** rather than replacing it with
  generated prose.
- **Do not submit a pull request you have not read and tested
  yourself.** See the AI policy.

## Repository layout

Standard R package. `R/` holds the source, `man/` is generated by
roxygen2 — edit the roxygen comments, never the `.Rd` files.
`tests/testthat/` holds the tests. CI lives in `.github/workflows/` as
thin stubs calling shared workflows in `animovement/.github`; change the
shared workflow, not the stub.
