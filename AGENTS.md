## Before you write code here

- **Verify that a function exists, and check its signature**, using the reference above. This suite
  is eight packages that went through a split and keeps evolving, so a plausible-sounding name may
  belong to a different package, may have changed signature, or may never have existed.
- **Format with [air](https://posit-dev.github.io/air/)**, not styler. Every pull request is checked,
  and formatting failures block merging.
- **Run the tests** — `devtools::test()`. Do not rely on code looking correct.
- **Do not push to `main`.** It is protected; open a pull request. Checks must pass before merging.
- **Fill in the pull request template** rather than replacing it with generated prose.
- **Do not submit a pull request you have not read and tested yourself.** See the AI policy.

## Repository layout

Standard R package. `R/` holds the source, `man/` is generated by roxygen2 — edit the roxygen
comments, never the `.Rd` files. `tests/testthat/` holds the tests. CI lives in `.github/workflows/`
as thin stubs calling shared workflows in `animovement/.github`; change the shared workflow, not the
stub.
